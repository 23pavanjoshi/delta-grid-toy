# AI Disclosure

## AI Tools Used

During this assignment, I used the following AI tools as development assistants:

* **Claude ** – architecture discussions, documentation review, and code review.
* **ChatGPT ** – brainstorming implementation ideas, reviewing approaches, and improving documentation.

---

## Background

I have several years of experience developing Unity games, including card-based multiplayer titles. Because of that, I was already familiar with the overall gameplay flow, state management, matching logic, and common edge cases before starting this assignment.

The project architecture and implementation decisions were based on my own experience and understanding of Unity development.

---

## How AI Was Used

### Brainstorming

I used AI to discuss different implementation approaches and think through a few edge cases, such as save/load behavior and input handling.

These discussions helped me compare different options, but the final implementation decisions were always mine.

### Code Review

Occasionally, I used Claude to review parts of my code and point out possible improvements or areas that could be simplified.

I reviewed every suggestion before deciding whether it was appropriate for this project.

### Documentation

AI was also used to improve the readability and structure of the project documentation after I had already completed the implementation.

---

## What AI Was Not Used For

AI was **not** used to generate the project architecture, gameplay systems, or production-ready code.

The complete implementation, debugging, testing, Unity scene setup, UI wiring, AudioManager, save/load system, Android build configuration, and project integration were completed by me.

## Final Note

I used AI as a development assistant to review ideas, improve documentation, and discuss implementation options.

The final codebase, project structure, technical decisions, and overall implementation are my own work, and I take full responsibility for the submitted project.
